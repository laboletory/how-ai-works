# Fox illustration set — gouache

Generated with the built-in ImageGen tool, using the approved `public/fox-training-gouache-v1.png` as the character and style reference. No CLI/API fallback was used.

Production assets: `public/illustrations/fox-*-gouache.webp`. Single scenes are 640px; the training triptych is 1600px wide. WebP encoding is for delivery only; no generated content was composited or painted in code. The approved first scene is reused as `fox-training-example-gouache.webp`.

These are teaching metaphors, not images of actual neural network internals. The exercise image `public/fox-moon.webp` remains unchanged.
