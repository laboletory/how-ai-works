# От шум до образ

Интерактивен образователен проект на български, който показва как един diffusion модел се обучава и как постепенно превръща шум в изображение.

Проектът използва достъпен ученически език по подразбиране. Техническите понятия и формули могат да се включат отделно от интерфейса.

## Локално стартиране

```bash
npm install
npm run dev
```

Отвори [http://localhost:3000](http://localhost:3000).

## Проверка за production

```bash
npm run build
npm run start
```

## Vercel

Импортирай GitHub repository-то като нов Vercel проект. Framework Preset трябва автоматично да бъде разпознат като **Next.js**. Не са нужни environment variables за основната функционалност.

По желание задай `NEXT_PUBLIC_SITE_URL` с окончателния публичен адрес, за да бъдат Open Graph линковете абсолютни още при build.
